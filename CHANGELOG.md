# Changelog

## 0.4.0 — Coverage

Added Brave, Mojeek, Kagi v1, Marginalia and Common Crawl metadata adapters; improved SearxNG pagination and upstream failures. Added environment credential handling, fixed-origin authentication, memory-only private caches, secret redaction, capability/configuration inventory, provider health and discovery diversity.

Settings now groups providers, offers six profiles, explicit locale/freshness controls, bounded budgets and privacy information. Query variants carry script/origin/kind and include conservative mechanical candidates. Duplicate discovery observations, native ranks and provider licenses persist and export. CLI includes diagnostics, coverage, refresh, Markdown/CSV exports and a versioned offline benchmark. Added schema migration 3, opt-in live tests, multi-platform CI and native release packaging.

Production lexical ranking remains version 2. Claims, semantic retrieval, arbitrary document fetching, temporal analysis and scale redesign are explicitly deferred. Live checks verified Common Crawl metadata and exposed Marginalia public-key rate limiting; paid providers were fixture-tested without live credentials.

## 0.3.0 — Tor discovery

Added public onion index search, separate Tor transport, lazy local proxy detection/startup, robots handling, and persistent continuation with no clearnet fallback. Preserved a single launch-screen wordmark.

## 0.2.0 — Resumable investigations

Added bounded fair retrieval, persisted page cursors, continuation/refresh, local history search, duplicate grouping, stable incremental results and richer exports.

## 0.1.0 — Initial desktop research engine

Introduced the native Qt application, six public API providers, multilingual label candidates, traceable provenance, local storage and evidence views.
